#Arogya
Arogya is a deep-learning based PCOS detection system that uses MobileNet to classify ovarian ultrasound images as PCOS-affected or healthy. Built with a Python backend and a React frontend, the model is trained on a Kaggle dataset of 7,700+ ultrasound images and uses preprocessing, augmentation, and depthwise separable convolutions for fast and accurate predictions. The system allows users to upload images, receive instant classification results, and supports secure storage and efficient inference. Arogya aims to provide an accessible, lightweight, and reliable AI tool to support early PCOS screening and women's healthcare.
