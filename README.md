Arogya — PCOS Detection Using Deep Learning

Arogya is a lightweight deep-learning based PCOS detection system that uses the MobileNet CNN architecture to classify ovarian ultrasound images as PCOS-affected or healthy. The project features a Python backend and a React frontend, trained on a Kaggle dataset of 7,700+ ultrasound images with preprocessing, augmentation, and depthwise separable convolutions for fast and accurate predictions. Users can upload ultrasound images and instantly receive classification results, supported by secure data handling and efficient inference. Arogya aims to provide an accessible, reliable, and scalable AI tool to support early PCOS screening and women’s healthcare.
